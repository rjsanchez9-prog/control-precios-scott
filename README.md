# control-precios-scott

Informe de control de precios SCOTT (BM Sportech).

La página `index.html` contiene el informe **cifrado** (AES-256-GCM, clave derivada con PBKDF2-SHA256, 600.000 iteraciones). Se descifra en el navegador al introducir la contraseña. Este repositorio no contiene datos en claro.
